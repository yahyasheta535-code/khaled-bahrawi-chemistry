# منصة أكاديمية خالد البحراوي — Production Notes

## المعمارية الحالية

التطبيق يستخدم Next.js App Router مع Prisma وقاعدة MySQL/TiDB. خوادم Next.js قابلة للتشغيل أفقيًا لأن الجلسات موقعة ولا تعتمد على ذاكرة instance واحدة. قاعدة البيانات هي مصدر الحقيقة للمستخدمين والمحاضرات والواجبات والدرجات، بينما تشغيل الفيديو والملفات الكبيرة يستخدم طبقة التخزين المباشر الموجودة في المشروع بدل تمرير البيانات الكبيرة عبر Backend.

```text
Browser -> CDN/Load Balancer -> Stateless Next.js instances -> MySQL/TiDB
                                             |                -> Storage direct upload/playback
                                             -> Redis/Queue (مطلوبان عند تفعيل rate-limit الموزع والـ jobs)
```

## ما تم تحسينه في هذه الدفعة

تم الحفاظ على أحدث تطويرات المستودع، بما فيها الرفع المباشر للتخزين، تشغيل الفيديو القابل للـ range requests، إدارة الأسئلة والصور والواجبات، وصلاحيات الطالب والمدرس. أضيفت حالات تحميل مرئية لصفحات تسجيل الدخول وإنشاء الحساب مع spinner ونقاط انتظار وتعطيل الحقول وخصائص `aria-busy` و`aria-live`. أضيفت كذلك نقاط `GET /api/health` و`GET /api/ready` لاستخدامها في فحوصات الاستضافة.

## حدود لا يجوز الادعاء بتجاوزها

لم يتم اعتبار المنصة قادرة على آلاف أو ملايين المستخدمين بدون اختبار حمل فعلي. يلزم تشغيل اختبارات تدريجية على بيئة مشابهة للإنتاج وتسجيل RPS وp95 وp99 ومعدل الأخطاء وحمل قاعدة البيانات. كما يلزم Redis خارجي لمحددات المعدل والكاش الموزع عند تشغيل عدة instances، وQueue خارجية للإشعارات والعمليات الطويلة.

يلزم Cloudflare Stream فعليًا للفيديوهات الكبيرة جدًا إذا كان المطلوب فصل التخزين والترميز والتسليم عن التطبيق. تفعيل ذلك يحتاج `CF_STREAM_ACCOUNT_ID` و`CF_STREAM_API_TOKEN` وwebhook processing status، ولا يجوز وضع أي منها في Frontend أو GitHub.

## التشغيل والنسخ الاحتياطي

استخدم migrations قابلة للمراجعة بدل `db push` في الإنتاج، واضبط `DATABASE_URL` وsession secret من مدير أسرار الاستضافة. يجب أخذ نسخ احتياطية دورية من قاعدة البيانات وتجربة restore، مع مراقبة أخطاء API وعمليات الرفع وتسجيلات الدخول. نقطة `/api/health` تقيس تشغيل العملية، بينما `/api/ready` تتحقق من اتصال قاعدة البيانات.
